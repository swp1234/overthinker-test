# Overthinking Loop Check

Static, multilingual 8-question reflection published at `/overthinker-test/`.

Each answer adds one point to one displayed thought loop. The highest count wins; ties use the first tied loop in question order. The result describes only the eight answers and is not a diagnosis or personality measurement.
